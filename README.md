# Chennai Restaurant Investment Guide

## Project Overview
Analyzed 11,345 restaurants across Chennai to answer:
**"What cuisine, area, price range and delivery model gives 
best success odds for a new restaurant in Chennai?"**

## Tools Used
- Python (Pandas) — Data Cleaning
- MySQL (DBeaver) — SQL Analysis  
- Power BI — Dashboard
- GitHub — Documentation

## Dataset
- Source: Zomato Chennai Listing 2020
- Rows: 11,345 restaurants
- Columns: 14

## Business Questions Answered
1. Top 10 most popular cuisines
2. Top 15 areas by restaurant count
3. Best price category by rating
4. Delivery vs Dine-in performance
5. Best cuisine + area combination

## Key Findings
1.Chinese cuisines dominates with (3430) but have higher competions,biriyani will offer strong demand and less competition , Niche cuisines like Rolls 
and Healthy Food achieve highest ratings (4.90, 4.60) 
with minimal competition — best entry point for new investors.
2.Top areas are concentrated in central chennai. So top recommendation is Velachery,Anna Nagar based on ratings
3.Mid range price category  works best for investors as it has highest rating(3.60) near to premium(3.85) .
4.Both service model works best as it is combination of dine-in and delivery (4244) has higher ratings than others.
5.Rolls+Egmore (4.90), Bakery+Royapettah (4.77), 
  Healthy Food+Thousand Lights (4.60) are highest rated combos
